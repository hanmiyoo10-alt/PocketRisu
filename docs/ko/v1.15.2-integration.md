# PocketRisu v1.15.2 Termux integration

Tracking: `hanmiyoo10-alt/-#3682`

## Scope

This integration imports official PocketRisu `v1.15.2` into the protected
Termux deployment line while preserving the server-phone contracts documented
in `custom-termux-deployment.md`.

The live-only Firefox overlay is deliberately **not** part of this integration
branch:

- `d6f00483` — avoid Android sound keepalive CPU kill
- `c9d96385` — trace same-process document recreation
- `fef7d4b0` — dehydrate large chat in background
- `d6a68402` — lazy-load inactive prompt presets

The exact pre-integration live state is preserved on remote ref
`backup/pre-v1.15.2-live-20261021`. The intentionally untracked
`generic_mock_bridge.cjs` also remains outside this integration branch.

The initially noticed release was v1.15.0, but a fresh upstream read before
candidate creation showed v1.15.2 was already the current official release.
The candidate therefore targets v1.15.2 rather than knowingly shipping an
older point release.

## Contract review

The merged tree retains the custom Termux deployment contracts:

- `/api/termux-notify` remains a relay to the main-phone listener and keeps
  `X-PocketRisu-Notify-Token`.
- server/client deployment sources do not invoke Android
  `termux-notification` on the server phone.
- background database persistence retains the save worker,
  `storageOperationQueue`, and `flushPendingDbUnlocked()` flow.
- database patch hash caching, plugin-storage routes, and
  `hydrateDatabaseForDisk()` remain present.
- v1.15.2 plugin-storage / KV-prefix changes coexist with the custom server
  persistence path.
- the v1.15.2 changes touching `server/node/server.cjs`,
  `DefaultChatScreen.svelte`, `PromptPresetSettings.svelte`, `bootstrap.ts`,
  and `database.svelte.ts` were inspected as semantic overlap points rather
  than assumed safe from the absence of textual conflicts.

`git diff --cached --check` passes.

## Termux dependency environment

Validation uses Termux Node `v26.4.0` and the installed pnpm module through:

```sh
node "$PREFIX/lib/node_modules/pnpm/bin/pnpm.cjs" ...
```

The candidate dependency tree accepts an offline frozen-lockfile install with
scripts disabled. The isolated candidate has the already-proven
`better-sqlite3@12.9.0` native module available for Android/arm64 validation.

PocketRisu v1.15.2 resolves the Vite line to `8.3.4`; production build succeeds
on this host.

## Deployment gate

This commit is integration-only. Live deployment remains incomplete until all
of the following have evidence:

1. the fork integration PR is green and merged;
2. the four live-only Firefox commits are replayed or deliberately reconciled
   on the exact merged v1.15.2 deploy target;
3. the inactive-preset lazy-hydration experiment is not silently promoted past
   its still-required real Firefox UI / persistence gate tracked in
   `hanmiyoo10-alt/-#2027`;
4. full source, runtime, and data rollback backups are taken immediately before
   cutover;
5. live source/runtime dependencies are switched with rollback anchors kept;
6. runit status, `/api/health`, SQLite quick checks, and restart persistence are
   verified;
7. main-phone Firefox chat/generation and main-phone notification smoke pass.

Safe-updater automatic deployment remains disabled; this integration commit
does not authorize live mutation by itself.
