# v1.12 live auto-sweep hotfix 검증

검증 일자: 2026-09-07

PocketRisu v1.12.0 + auto-sweep queue deadlock hotfix의 실제 live 동작을 메인폰 클라이언트가 열린 상태에서 확인했다.

## 배포 기준

- hotfix commit: `83464f845a8d34d147dd24f8bdd07c2b8a9f343f`
- package version: `1.12.0`
- 배포 updater 실제 새-target `--apply`: PASS

## 실사용 검증

메인폰에서 PocketRisu/Firefox를 다시 열고 자동 `cleanChunks()` / `/api/db/assets/auto-sweep`가 실행될 수 있는 시간을 지난 뒤 서버 상태를 확인했다.

- live service PID: `8255`
- `/api/health`: `ready`
- uptime: 약 2118초
- 클라이언트가 열린 상태에서 health 유지: PASS

같은 상태에서 `sv down`으로 graceful shutdown을 검증했다.

- 서비스가 약 1초 안에 `down` 상태로 전환: PASS
- `LIVE_STOP=PASS`
- `sv up` 후 새 PID `18974`로 재기동 확인

따라서 기존의 `storageOperationQueue -> computeAssetSweep() -> flushPendingDb()` 자기 재진입 deadlock은 live hotfix 적용 후 재현되지 않았고, 메인 클라이언트가 열린 상태에서도 SIGTERM shutdown이 더 이상 해당 queue deadlock에 막히지 않는 것으로 검증했다.
