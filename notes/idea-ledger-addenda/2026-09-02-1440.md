### Durable invariant

Responsive shell defaults may be re-applied when the viewport crosses a semantic layout-mode boundary, but user-owned state must survive resizes that remain inside the same mode. Lifecycle re-sampling is detection only: it must not mutate shell state unless a real breakpoint crossing occurred. Breakpoints expected to remain responsive must use reactive state rather than mount-only `window.innerWidth` samples.

### Dedupe

Keep separate from general mobile-light/performance and fixed-size picker/layout records. This item owns breakpoint-transition state authority, not static mobile sizing or rendering budgets.
